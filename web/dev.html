    2. Open a save file from the desktop app

    Your profiles live in C:\Invenfloor\data\ while you run from source, or %APPDATA%\InventoryApp\data\ once it is packaged. Pick any .json in there. Nothing is uploaded anywhere; the file is read in this page and thrown away when you close the tab.

Invenfloor

Draw your floor plan, put shelves in it, and find where things are.

Open it

Nothing you put in it leaves your device

There is no account and no server. What you draw is saved by your own browser, on the machine you drew it on, and you can put a passphrase over it. Clearing your site data clears it, so there is a Download button on every profile for keeping a copy.

It is being tested, so it will have rough edges

If something goes wrong, the bottom of the app has a "Something wrong?" button that writes out which browser you are on and whether the page was able to save anything. Send that over with what you were doing and it is usually enough to find the problem.

There is a desktop version for Windows as well, with more in it. The code is on GitHub.
